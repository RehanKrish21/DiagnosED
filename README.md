# DiagnosED Marketing Website

Ready for GitHub Pages.

1. Upload every file and the `assets` folder to the root of your GitHub repository.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch**, then `main` and `/(root)`.
4. Use the resulting URL for the App Store Marketing URL.
